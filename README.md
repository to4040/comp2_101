```
今日の朝、私は朝のアラームとの戦いに敗北しかけました。

アラームが鳴った時に、起きなければいけないことはわかっていました。
しかし、ベッドの中はあまりにも心地よすぎました。あと5分だけ寝よう
と思いアラームを止め、気づけば起きる時間を過ぎていました。

慌てながら起きて準備を始め、なんとか家を出ることができました。
朝から遅刻という大きな戦いとの決着をつけることができたが、
その戦いの相手は相手はただのベッドでした。

明日こそは余裕を持って起きたい。
と思いながら、今夜も明日のアラームをセットしました。

```
